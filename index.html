    Schedule an operation
    
      
    
      
    
      
    
      
    
      
    
    
    
    
    How scheduled operations work
    • Running servers receive warnings 5 minutes and 1 minute before a restart, stop or update. Failed or missed warnings skip that run.
    • Warnings require working admin RCON and Server Admin Tools #message support.
    • Updates stop the game first, then restart it only if it was previously running and the update succeeded.
    • Backups include server configuration only; the latest 20 versions are kept in Administration → Maintenance.
    • Jobs run while the Linux panel service is active. Missed runs are reported, not replayed. Daily/weekly repeats follow the server clock. Nonexistent daylight-saving times are skipped; repeated times run once. Hour intervals use elapsed hours.
