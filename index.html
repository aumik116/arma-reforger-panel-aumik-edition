Persistence
Server launches always pass -loadSessionSave, so any existing save is loaded on start. This toggle writes the game.gameProperties.persistence block in config.json — enable to autosave every N minutes, disable to stop writing new saves (existing saves still load on start; use Flush saves to start fresh). Session save only works in scenarios that implement it (Conflict, Combat Ops); Game Master needs manual saves from Esc.
⚠ Restart required for persistence changes to take effect
