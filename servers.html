About these readings

Metrics stream about every 2 seconds, with a 10-second polling fallback. Other information refreshes every 10 seconds. Unit filters affect server totals and player trends. Search and status filters affect rows only. Host CPU and memory cover the whole VM. A + marks incomplete player totals. Rows show game-process CPU and memory; process CPU can exceed 100% across cores. Storage is measured on request and cached for 10 minutes.

Master update

Select servers to update to the public Steam release. Game files download once before any server stops. Each selected server is then stopped, copied and validated. Only servers running when you confirm are restarted.

Connected players will be disconnected. Workshop mods, settings and saves are not updated. A failed installation stays stopped for review.
